# Responsive image derivatives

Generated from the existing JPEG assets with `scripts/optimize-media.py`.

- `hero-640.webp`: 640×360 mobile hero, WebP quality 78.
- Photo variants: 640px and up to 960px wide, WebP quality 84. The 900px dining-room source is not upscaled; its largest file retains the `-960` naming tier and is correctly declared as 900w in the page.
- Original images and their attribution remain in `../photos/` and `../sequence/`.
- The source animation JPEGs are already compact and are served unchanged on eligible desktop devices.
